# Linux 1.0 · M4 界面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `cellglide-gui` 从一个小状态窗口做成完整应用：带侧栏的主窗口（概览、测速、DNS 泄漏检测、连接记录、诊断、设置、关于）、托盘左键面板与两态加橙点的托盘图标、完整与简版手机卡片；同时收掉 M3 留给 M4 的服务与 CLI 小项（睡眠唤醒重置判定、断开时的健康行、夏令时色条、星期、诊断手机行、ECS 文案、只测 Wi‑Fi 提示、sudo 诊断提示），并在测试机（GNOME）与 KDE 虚拟机上实测。

**Architecture:** 界面仍是 iced 0.14 daemon，一个进程两种窗口（主窗口、面板），托盘与服务订阅沿用 `tray::events`。每页一个模块，页面状态与 `update` 是纯逻辑：`update` 不直接做 I/O，而是返回 `Effect`（请求服务、开始测速、上传、复制、写偏好…），由 `App::run_effect` 统一变成 `iced::Task`；测试直接断言返回的 `Effect`，不需要显示器。手机卡片、走势、色条、测速曲线、长文本分页放在 `widgets`。用户能看到的句子都由 `cg-ipc::describe`、`cg-tools` 与 `cg-gui` 通过 `cg_i18n::tr` 取自 yml。线上只加一个字段（`Snapshot.socks_port`，供「手动代理地址」），协议升到 5。

**Tech Stack:** Rust 2024；iced 0.14（`tokio`、`canvas`、`image` 特性）、ksni 0.3.6、zbus 5（服务端新用来收 logind 的 `PrepareForSleep`）；沿用 cg-tools（测速、DNS 泄漏、`uplink`）、cg-diag（上传）、jiff 0.2；开源许可清单用 cargo-about 生成（开发工具，不是依赖）。

**Spec:** `docs/specs/2026-10-16-linux-1.0-full-design.md`（§3 反目标、§4.1–4.9、§5 M4 行、§6、§6.1、§7），以及它修订的 `docs/specs/2026-10-15-linux-1.0-design.md`（§3.8 自启与 `Hidden=true` 覆盖）。M3 遗留：`docs/validation/linux-1.0-m3-execution-notes.md`「留下的小问题」与 `docs/validation/linux-1.0.md`「M3 · 问题与留到 M4」。Mac 蓝本：`CellProxy:Desktop/macOS/CellProxyMac/App/{MainWindow,PanelView,PhoneCard,ConnectionHealthViews}.swift`、`App/Pages/*.swift`、`CellProxy:Sources/DesktopCore/MainSectionBadge.swift`。

**计划层面的决定（spec 细化，执行者照此做）：**

1. **页面 = 纯状态 + `Effect`。** 每页模块导出 `State`、`Msg`、`update(&mut State, Msg, &Ctx) -> Effect`、`view(&State, &Ctx) -> Element<Msg>`。iced 的 `Task` 在测试里只能数 `units()`，看不出「会不会上传」「上传的是哪份字节」；`Effect` 是 `Debug + PartialEq` 的枚举，测试能逐项断言。I/O 只在 `App::run_effect` 一处，`Target::production()` 也只在那里出现。例外：测速记录文件很小，由测速页自己持有 `HistoryStore`（测试用临时目录）。
2. **一个进程两种窗口。** 主窗口与面板都由 daemon 打开，都设 `application_id = "cellglide"`，GNOME Dock 只会显示一个 CellGlide。面板无边框、置顶、不可缩放，失焦关闭；Wayland 下位置由桌面决定（spec §4.2 已接受）。
3. **面板失焦的兜底。** GNOME Wayland 可能不给新窗口焦点（防抢焦点），那样永远收不到失焦。面板只有在「得到过焦点后失焦」时才关；另外再点一次托盘、按 Esc、点「打开 CellGlide…」、或打开 60 秒仍未得到过焦点时也关。实机记录实际行为。
4. **托盘图标用四个自带的 symbolic SVG**（`cellglide-tray[-active][-alert]-symbolic`），装到 hicolor。手机外形由 GNOME 与 Plasma 按面板颜色重新着色；橙点不带任何着色类，始终是固定橙色。ksni 的 `icon_pixmap` 不能随面板深浅变色，`overlay_icon_name` 在 GNOME 扩展里不可靠，所以不用。
5. **侧栏无图标**：iced 没有 SF Symbols，图标字体要新依赖；侧栏只用文字和提醒点。
6. **提醒点（照 `MainSectionBadge.swift` 改写）**：概览——健康问题严重时红点、其他问题橙点；没有问题但连接在等用户（`Retrying`、`ChoosePhone`）时橙点；`Connecting` 不标（Mac 同样不标正在启动）。连接记录——有未结束的问题时与概览同色（spec §4.1 的例子）。设置——当前用户不在 `cellglide` 组，或已连接但 `DnsMode::Unmanaged` 时橙点（对应 Mac 的后台权限）。关于——Linux 没有应用内更新，不标。
7. **「手动代理地址」需要服务告诉界面 hev 用的转发端口**，这是本里程碑唯一的线上改动：`Snapshot.socks_port: Option<u16>`，显示为 `socks5h://127.0.0.1:<port>`（与 Mac `DesktopModel` 相同）。`PROTOCOL_VERSION = 5`。
8. **诊断「先看后发」比 Mac 更严**：「发送」只有在当前这份诊断包已经在预览里打开过之后才可用；任一字段（范围、邮箱、备注）一改，旧包作废，要重新预览。上传的字节就是预览的那串 `json`。预览按行分页（每页最多 200 行且最多 32 KiB，切在行尾），1 MB 的包约 30 页。
9. **「保存到文件」不弹文件对话框**：写到下载目录（`~/.config/user-dirs.dirs` 的 `XDG_DOWNLOAD_DIR`，没有就 `~/Downloads`，再没有就 `~`），文件名 `cellglide-diagnostics-YYYYMMDD-HHMMSS.json`、权限 0600、不覆盖已有文件，然后显示路径与「打开所在文件夹」。照 Mac「导出…」写固定位置再在访达里显示的做法；免去 rfd 与 portal 依赖。
10. **偏好放在 `$XDG_CONFIG_HOME/cellglide/gui.json`**（相对路径或未设时 `~/.config`）：`speed_confirmed`（测速「不再提示」）、`include_wifi`（默认 true）、`open_on_plug`（默认 false，同 Mac 默认未开）。登录启动不进偏好：它的状态就是 `~/.config/autostart/cellglide-gui.desktop` 本身（1.0 设计 §3.8）。
11. **读不到就不显示**（spec §3 反目标）：Mac 在连接记录快照里对未知项显示「—」，这里直接不列；走势里缺的秒是断开的线段，不画成 0（M3 P16）。
12. **不移植**：Mac 的 `SessionTrafficRow`（依赖 Mac 的目的地账本，Linux 没有数据源；卡片里「本次 X」已给出用量）、`NetworkFootprintRow`、`ProxyOnlyNotice`、移到「应用程序」、更新按钮、分流、地图。
13. **文案**：中文取 Mac 的 zh 原句（`Localizable.strings` 的键），英文取 `CellProxy:Sources/SharedLocalization/Resources/en.lproj/Localizable.strings` 同一键，「Mac」改为「电脑 / computer」。本计划列「键 → 中文」；标「新」的是 Linux 新句子，给出中英文；其余英文照 Mac 文件查。界面代码只用字面量键（`tr("settings.proxy", …)`），不用 `format!` 拼键，以便 Task 7 的扫描测试能覆盖。

## Review Focus

1. **服务在请求途中重启、停掉或换了版本**（升级、`systemctl restart`）：连接记录、诊断、doctor、设置写入都要结束「正在…」状态并显示原因，不能永远转圈；订阅断开后回来，页面照常。测试在 Task 7（`request_failure_reaches_the_page_as_text`）与 Task 14（`service_error_ends_preparing`）。
2. **「插入 iPhone 时打开窗口」误触发**：界面启动时手机本来就插着、服务重启后第一份快照、选择的手机变了，都不算「插上」；拔掉再插回才算。测试在 Task 15（`plug_detection_ignores_first_snapshot_and_service_restarts`）。
3. **面板在 Wayland 下从未得到焦点**（GNOME 防抢焦点）或用户连点托盘：面板不能留在屏幕上关不掉，也不能开出第二个。测试在 Task 9（`panel_that_never_got_focus_still_closes`）。
4. **测速中或数据提醒弹着时拔掉手机 / 断开**：提醒自动收起，不在没有手机时开始手机线路；正在跑的手机线路以「连接 iPhone 后才能测手机线路」结束，Wi‑Fi 线路照跑，不记历史。测试在 Task 11（`phone_leaving_closes_the_data_warning`、`unplug_mid_run_records_nothing`）。
5. **用户自己的 autostart 文件或 `XDG_CONFIG_HOME`**：用户写过 `~/.config/autostart/cellglide-gui.desktop`（例如改了 Exec），开关登录启动只改 `Hidden=`，不删用户的文件；`XDG_CONFIG_HOME` 是相对路径时按规范忽略。测试在 Task 15（`user_file_is_edited_not_deleted`、`relative_xdg_config_home_is_ignored`）。

### Task 3: 连接记录的日期与色条：星期、夏令时

**Files:**
- Modify: `crates/cg-ipc/src/health.rs`、`crates/cg-ipc/src/describe.rs`
- Modify: `crates/cg-i18n/locales/{zh-CN,en}.yml`、`crates/cg-i18n/src/lib.rs`

**Interfaces:**
- Produces（`cg_ipc::health`）：
  - `pub fn day_bounds(day: jiff::civil::Date, tz: &TimeZone) -> Option<(Timestamp, Timestamp)>`：当天本地零点与次日本地零点（夏令时那天是 23 或 25 小时）。
  - `pub fn strip_fraction(t: Timestamp, begin: Timestamp, next: Timestamp) -> f64`：`(t - begin) / (next - begin)`，夹在 0–1。
