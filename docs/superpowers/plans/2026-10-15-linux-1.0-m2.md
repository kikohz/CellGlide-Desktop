# Linux 1.0 · M2 权限与安装包 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 服务改为专用用户 `cellglide`、只带 CAP_NET_ADMIN 运行；出 x86_64 与 arm64 的 deb / rpm 安装包（在 Ubuntu 22.04 容器中构建）；建立 GPG 签名的 apt / dnf 软件源托管在 `pkg.cellglide.com`；六个发行版安装测试通过；发布 `1.0.0~beta1` 并在测试机上从软件源安装。

**Architecture:** 先用一次实测（Task 2）确定 systemd-resolved 在各发行版上是否允许持有 CAP_NET_ADMIN 的非 root 进程设置单网卡 DNS，结果决定是否随包安装 polkit 规则。服务端改动集中在 `cg-service`（去掉 root 检查、改查能力位、放行自身 uid）、`cg-platform::resolved`（识别「无权限」并不接管 DNS）与 `cg-ipc`（`Connected` 的 DNS 状态改为三值枚举，协议升到 3）。打包配置放在 `cg-service/Cargo.toml` 的 `[package.metadata.deb]` 与 `[package.metadata.generate-rpm]`，静态文件放在 `packaging/`。构建、签名、发布各一个脚本：`scripts/build-packages.sh`（容器内构建）、`scripts/sign-and-publish.sh`（在 Mac 上签名并上传 R2）。

**Tech Stack:** 在 M1 之上新增 cargo-deb 3.8、cargo-generate-rpm 0.21、Docker（Mac）/ Podman（x86_64 构建机）、GnuPG（Mac）、rpm 与 createrepo_c（Mac，brew）、apt-ftparchive（容器内）、wrangler（R2 上传）。

**Spec:** `docs/specs/2026-10-15-linux-1.0-design.md`（§3.5、§3.8 自启部分、§3.9、§4、§5、§6 的 M2 行）。M1 计划与执行记录：`docs/superpowers/plans/2026-10-15-linux-1.0-m1.md`、`docs/validation/linux-1.0-m1-execution-notes.md`。

**计划层面的决定（spec 细化）：**
1. Debian 12 / 13 默认不使用 systemd-resolved。安装包把 `systemd-resolved` 列为 **Suggests**（rpm 为 `Suggests:`），而不是 Depends 或 Recommends：apt 与 dnf 默认都会自动安装 Recommends，而安装 resolved 会改变整台机器的 DNS 管理方式，违背 `AGENTS.md`。没有 resolved 时 `cellglide doctor` 给出安装命令（M1 已有该检查）。
2. spec §4「resolved 不允许改 DNS → 不接管 DNS」落地为：隧道照常建立，`ConnState::Connected` 的 `phone_dns: bool` 改为 `dns: DnsMode { Phone, Public, Unmanaged }`；`Unmanaged` 时界面与命令行提示原因与修复命令。线上格式变化，`PROTOCOL_VERSION` 升到 3。
3. 版本号：测试版 `1.0.0~beta1`（deb 与 rpm 都把 `~` 排在正式版之前）。
4. 包内程序安装到 `/usr/bin`；`scripts/install-dev.sh` 继续装到 `/usr/local/bin`，并在安装 systemd 单元时把 `ExecStart` 改写为 `/usr/local/bin/…`。
5. x86_64 包在构建机（当前为 <build-host>）上用 Podman 构建；arm64 包在开发 Mac 上用 Docker 构建。GPG 私钥只在开发 Mac 上，签名与上传都在 Mac 上做。

## Global Constraints

`scripts/probe-resolved-auth.sh`（在虚拟机里以 root 运行）：

```bash
#!/bin/bash
# Can a non-root service holding only CAP_NET_ADMIN set per-link DNS through
# systemd-resolved, with and without a polkit rule? Prints one RESULT line per case.
# Usage (as root): probe-resolved-auth.sh
set -u
U=cgprobe
IF=cgauth0
BUS="org.freedesktop.resolve1 /org/freedesktop/resolve1 org.freedesktop.resolve1.Manager"
id "$U" >/dev/null 2>&1 || useradd --system --no-create-home --shell /usr/sbin/nologin "$U"
ip tuntap add dev "$IF" mode tun user "$U"
ip link set "$IF" up
IDX=$(cat "/sys/class/net/$IF/ifindex")
trap 'busctl call $BUS RevertLink i "$IDX" >/dev/null 2>&1; ip link del "$IF" 2>/dev/null; rm -f /usr/share/polkit-1/rules.d/49-cgprobe.rules /var/lib/polkit-1/localauthority/10-vendor.d/cgprobe.pkla /etc/polkit-1/localauthority/10-vendor.d/cgprobe.pkla' EXIT

attempt() { # $1 = label, $2 = extra systemd-run properties
    out=$(systemd-run --quiet --wait --pipe --collect -p User="$U" $2 \
        busctl call $BUS SetLinkDNSEx 'ia(iayqs)' "$IDX" 1 2 4 127 0 0 1 1053 "" 2>&1)
    if [ $? -eq 0 ]; then echo "RESULT $1: allowed"; else echo "RESULT $1: denied ($out)"; fi
    busctl call $BUS RevertLink i "$IDX" >/dev/null 2>&1 || true
}

echo "distro: $(. /etc/os-release; echo "$PRETTY_NAME")"
echo "systemd: $(systemctl --version | head -1)"
echo "polkit: $(pkaction --version 2>/dev/null || echo none)"
attempt "no-capability" ""
attempt "cap-net-admin" "-p AmbientCapabilities=CAP_NET_ADMIN -p CapabilityBoundingSet=CAP_NET_ADMIN"

# Same with a polkit rule for the probe user (JS for polkit >= 0.106, pkla for 0.105).
if [ -d /usr/share/polkit-1/rules.d ] && pkaction --version 2>/dev/null | grep -vq " 0\.105"; then
    cat > /usr/share/polkit-1/rules.d/49-cgprobe.rules <<EOF
polkit.addRule(function (action, subject) {
    if (subject.user === "$U" && action.id.indexOf("org.freedesktop.resolve1.") === 0) { return polkit.Result.YES; }
});
EOF
else
    d=/var/lib/polkit-1/localauthority/10-vendor.d
    mkdir -p "$d"
    printf '[cgprobe]\nIdentity=unix-user:%s\nAction=org.freedesktop.resolve1.*\nResultAny=yes\nResultInactive=yes\nResultActive=yes\n' "$U" > "$d/cgprobe.pkla"
fi
sleep 2
attempt "no-capability+polkit" ""
attempt "cap-net-admin+polkit" "-p AmbientCapabilities=CAP_NET_ADMIN -p CapabilityBoundingSet=CAP_NET_ADMIN"
```

- [ ] **Step 2: 实现**

`cg-ipc/src/lib.rs`：

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum DnsMode {
    /// The phone's encrypted DNS through our local resolver.
    Phone,
    /// Public resolvers through the tunnel (the phone's CellGlide DNS is off).
    Public,
    /// The system wouldn't let CellGlide set DNS; lookups use the original network.
    Unmanaged,
```

```rust
#[derive(Debug)]
pub enum ApplyError {
    /// resolved (polkit) refused the caller; the tunnel can run without our DNS.
    NotAuthorized(String),
    Failed(TunnelError),
}

fn classify(error: zbus::Error) -> ApplyError {
    let text = error.to_string();
    let denied = matches!(&error, zbus::Error::MethodError(name, _, _)
        if name.as_str() == "org.freedesktop.DBus.Error.AccessDenied"
            || name.as_str() == "org.freedesktop.DBus.Error.InteractiveAuthorizationRequired");
    if denied { ApplyError::NotAuthorized(text) } else { ApplyError::Failed(TunnelError(format!("systemd-resolved refused the DNS settings: {text}"))) }
}
```

`apply` 返回 `Result<(), ApplyError>`，连不上 D-Bus 或找不到 resolved 仍为 `Failed`。（`zbus::Error::MethodError` 的字段形状以 zbus 5.19 为准，只调整模式匹配写法。）

`backend.rs`：`resolved::apply` 返回 `NotAuthorized` 时，`tracing::warn!("systemd-resolved won't let this service set DNS ({detail}); running without managed DNS")`，先 `resolved::revert` 一次（忽略结果），继续建立隧道，`Running` 记 `dns_managed: false`；`Failed` 维持原来的失败处理。`impl RunningTunnel for Running` 实现 `dns_managed`。

```sh
# Builds the deb and rpm for this machine's architecture inside the Ubuntu 22.04 builder.
```

```bash
#!/bin/bash
# Installs a local CellGlide package in a fresh Lima VM, checks the service, upgrades to a
# second package if given, then removes it and checks nothing is left behind.
# Usage: scripts/test-install-vm.sh <lima template> <package> [<newer package>]
set -euo pipefail

limactl start "$VM" >/dev/null
trap 'limactl delete -f "$VM" >/dev/null 2>&1 || true' EXIT

limactl copy "$ROOT/scripts/network-snapshot.sh" "$VM":/tmp/snap.sh
limactl copy "$PKG" "$VM":/tmp/
[ -n "$NEWER" ] && limactl copy "$NEWER" "$VM":/tmp/
case "$PKG" in
    *.deb) INSTALL="apt-get install -y"; REMOVE="apt-get purge -y cellglide" ;;
    *.rpm) INSTALL="dnf install -y"; REMOVE="dnf remove -y cellglide" ;;
esac
run "bash /tmp/snap.sh > /tmp/before.txt"
echo "== install $(basename "$PKG") on $T"
run "$INSTALL /tmp/$(basename "$PKG")"
run "id cellglide && systemctl is-active cellglide && systemctl show cellglide -p User -p AmbientCapabilities"
run "cellglide settings --auto-connect off && cellglide settings"
run "cellglide doctor || true"
run "test -f /etc/xdg/autostart/cellglide-gui.desktop && test -f /usr/share/icons/hicolor/256x256/apps/cellglide.png"
if [ -n "$NEWER" ]; then
    echo "== upgrade to $(basename "$NEWER")"
    run "$INSTALL /tmp/$(basename "$NEWER")"
    run "systemctl is-active cellglide && cellglide settings | head -1"
    run "grep -q '\"auto_connect\": false' /var/lib/cellglide/settings.json && echo settings kept"
fi
echo "== remove"
run "$REMOVE"
run "! systemctl is-active --quiet cellglide && ! ip link show cellglide0 2>/dev/null && ! ip route | grep -q 'realm 198' && echo clean"
run "bash /tmp/snap.sh > /tmp/after.txt; diff /tmp/before.txt /tmp/after.txt && echo network unchanged"
echo "== PASS $T"
```

- [ ] **Step 1: 发布脚本**

`scripts/sign-and-publish.sh`（在开发 Mac 上运行；`brew install rpm` 提供 `rpmsign`；apt / rpm 元数据在容器里生成，签名在 Mac 上用本机 GnuPG）：

```bash
#!/bin/bash
# Signs the packages in dist/<version> and the repository metadata with the CellGlide key,
# assembles repo/ (apt + rpm) from every version in dist/, and uploads it to R2.
# Usage: CELLGLIDE_GPG_KEY=<fingerprint> scripts/sign-and-publish.sh <version> [--dry-run]
set -euo pipefail
ROOT=$(cd "$(dirname "$0")/.." && pwd)
VERSION=${1:?usage: sign-and-publish.sh <version> [--dry-run]}
DRY=${2:-}
KEY=${CELLGLIDE_GPG_KEY:?set CELLGLIDE_GPG_KEY to the signing key fingerprint}
BUCKET=cellglide-pkg
REPO="$ROOT/repo"

# 1. Sign the new rpms (debs are covered by the signed Release file).
for rpm in "$ROOT/dist/$VERSION"/*.rpm; do
    rpmsign --define "_gpg_name $KEY" --addsign "$rpm"
done

# 2. Lay out the repository from every built version.
rm -rf "$REPO" && mkdir -p "$REPO/apt/pool/main/c/cellglide" "$REPO/rpm/x86_64" "$REPO/rpm/aarch64"
cp "$ROOT"/dist/*/*.deb "$REPO/apt/pool/main/c/cellglide/"
cp "$ROOT"/dist/*/*.x86_64.rpm "$REPO/rpm/x86_64/" 2>/dev/null || true
cp "$ROOT"/dist/*/*.aarch64.rpm "$REPO/rpm/aarch64/" 2>/dev/null || true

# 3. Metadata, generated in containers.
docker run --rm -v "$REPO/apt":/repo -w /repo ubuntu:22.04 bash -c '
    apt-get update -qq && apt-get install -y -qq apt-utils >/dev/null
    for arch in amd64 arm64; do
        mkdir -p dists/stable/main/binary-$arch
        apt-ftparchive --arch $arch packages pool > dists/stable/main/binary-$arch/Packages
        gzip -9kf dists/stable/main/binary-$arch/Packages
    done
    apt-ftparchive -o APT::FTPArchive::Release::Origin=CellGlide -o APT::FTPArchive::Release::Label=CellGlide \
        -o APT::FTPArchive::Release::Suite=stable -o APT::FTPArchive::Release::Codename=stable \
        -o APT::FTPArchive::Release::Architectures="amd64 arm64" -o APT::FTPArchive::Release::Components=main \
        release dists/stable > dists/stable/Release'
docker run --rm -v "$REPO/rpm":/repo -w /repo fedora:42 bash -c '
    dnf install -y -q createrepo_c >/dev/null
    createrepo_c x86_64 && createrepo_c aarch64'

# 4. Sign the metadata on this Mac.
gpg --batch --yes --default-key "$KEY" --clearsign -o "$REPO/apt/dists/stable/InRelease" "$REPO/apt/dists/stable/Release"
gpg --batch --yes --default-key "$KEY" -abs -o "$REPO/apt/dists/stable/Release.gpg" "$REPO/apt/dists/stable/Release"
for arch in x86_64 aarch64; do
    gpg --batch --yes --default-key "$KEY" --detach-sign --armor -o "$REPO/rpm/$arch/repodata/repomd.xml.asc" "$REPO/rpm/$arch/repodata/repomd.xml"
done
cp "$ROOT/packaging/keys/RPM-GPG-KEY-cellglide" "$REPO/"
cp "$ROOT/packaging/keys/cellglide-archive-keyring.gpg" "$REPO/"

# 5. Upload.
if [ "$DRY" = "--dry-run" ]; then
    echo "dry run: repository at $REPO, nothing uploaded"; exit 0
fi
cd "$REPO"
find . -type f | sed 's#^\./##' | while read -r f; do
    npx --yes wrangler@4.31.0 r2 object put "$BUCKET/$f" --file "$f" --remote >/dev/null
    echo "uploaded $f"
done
```
